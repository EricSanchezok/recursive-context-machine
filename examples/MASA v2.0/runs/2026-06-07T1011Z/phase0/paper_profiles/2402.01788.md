## Method Description

LitLLM is a modular RAG-based toolkit for scientific literature review that combines keyword extraction, semantic re-ranking, and related-work generation. The system is designed as a flexible toolkit rather than a monolithic pipeline, allowing researchers to use individual components independently.

The workflow consists of: (1) Keyword Extraction — given a topic or abstract, the system extracts key terms using LLM-based analysis; (2) Paper Retrieval — extracted keywords are used to query academic search APIs (Semantic Scholar); (3) Re-ranking — retrieved papers are re-ranked using embedding similarity to the original query, improving relevance beyond keyword matching; (4) Related-Work Generation — the top-ranked papers are used as context for generating a related-work section via LLM prompting.

LitLLM's design emphasizes modularity and ease of use. Each component can be called independently via a Python API, making it suitable as a building block for more complex survey generation pipelines. The generation component is limited to related-work sections rather than full surveys, positioning it as a focused summarization tool rather than a complete survey system.

- LLM-based keyword extraction for improved search query formulation
- Two-stage retrieval (keyword search + embedding re-ranking)

## Method Category

single_agent_pipeline

## Category Rationale

LitLLM uses a single LLM for keyword extraction and related-work generation. The pipeline is sequential and single-pass. The contribution is modular toolkit design and two-stage retrieval, not multi-agent coordination or iterative refinement.

## Limitations

- Generates related-work sections only, not full surveys
- No citation graph awareness — entirely dependent on search API quality
- Single-pass with no refinement or quality checking
- No explicit citation verification mechanism
