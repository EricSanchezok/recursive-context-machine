## Method Description

This paper proposes a multi-agent system for conducting systematic literature reviews, where different AI agents are assigned specific SLR tasks. The agents include a Search Agent for database querying, a Screening Agent for relevance assessment, an Extraction Agent for data extraction, and a Synthesis Agent for generating the review narrative.

The agents operate sequentially: Search Agent queries multiple academic databases and compiles results; Screening Agent applies inclusion/exclusion criteria to filter irrelevant papers (with conflict resolution mechanisms); Extraction Agent extracts structured data from included full texts; Synthesis Agent produces narrative synthesis organized by research questions. Each agent records its decisions and justifications for auditability.

The system is designed for traditional SLR methodology rather than open-ended survey generation. It focuses on answering pre-defined research questions through systematic, reproducible methods. The multi-agent design provides modularity — each agent can be updated independently as LLM capabilities improve.
