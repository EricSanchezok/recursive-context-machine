## Method Description

This paper presents a self-supervised pretraining approach for Graph Neural Networks (GNNs) applied to the task of retrieving related mathematical expressions from academic literature. The method constructs graphs where nodes represent mathematical expressions (equations, symbols, terms) and edges represent co-occurrence, syntactic, or semantic relationships. A GNN encoder is pretrained using self-supervised objectives — such as masked expression prediction and contrastive learning between related expression pairs — to learn expressive embeddings of mathematical content.

The pretrained GNN embeddings can then be used for retrieval: given a query mathematical expression, the system retrieves related expressions from a database by computing embedding similarity. While domain-specific (math expressions), the methodology is transferable to general citation graph embedding — the self-supervised graph pretraining approach using contrastive and masked objectives can be applied to paper citation graphs for literature retrieval.
