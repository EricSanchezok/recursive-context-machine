## Method Description

SurveyEval is an evaluation framework for automated survey generation covering seven academic subjects (computer science, physics, biology, medicine, engineering, social sciences, and humanities). It uses both LLM-as-a-Judge scoring and human-written reference surveys for alignment evaluation.

The benchmark provides topic seeds and reference surveys for each of the seven subjects, enabling cross-disciplinary evaluation. The LLM-as-a-Judge component uses structured rubrics covering coverage, coherence, citation quality, and readability. Human evaluation on a subset validates that LLM-as-a-Judge scores correlate with human preferences.

SurveyEval's seven-subject coverage is notable — most other benchmarks focus on single disciplines (typically CS). This enables evaluation of survey system generalizability across scientific domains with different publication patterns, citation conventions, and discourse structures.
