## Method Description

This paper uses grammar-guided genetic programming (G3P) with evolutionary rule-based classification for automatic paper selection in systematic reviews. The method evolves interpretable classification rules (e.g., IF abstract contains "deep learning" AND year > 2020 THEN relevant) using a genetic algorithm guided by a grammar that constrains rule structure.

The interpretable rules are a key advantage over black-box classifiers — researchers can understand and validate the screening criteria. The evolutionary approach searches the rule space to find compact, accurate classification rules that balance precision and recall.
