## Method Description

InteractiveSurvey enables user customization of references, outline, and content mid-generation. Unlike fully automated systems that produce a survey in one pass, InteractiveSurvey supports: (1) reference customization — users can add or remove specific papers from the survey's reference list, (2) outline customization — users can modify the section structure before and during generation, (3) content customization — users can request specific writing styles, depth levels, or emphasis on particular aspects.

The interactive interface allows users to guide the survey generation process at multiple points, providing a human-in-the-loop approach that ensures the final survey matches the user's specific needs. The system adapts its generation based on user feedback at each stage.

## Limitations

- Requires active user participation throughout generation
- User customization may slow down the generation process
- Quality depends on user's ability to provide effective guidance
- Does not incorporate citation graph traversal for discovery
