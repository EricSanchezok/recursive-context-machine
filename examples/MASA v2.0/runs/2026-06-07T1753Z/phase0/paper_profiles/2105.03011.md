## Method Description

QASPER is a dataset of 5,049 information-seeking questions over 1,585 NLP papers, designed for evaluating scientific QA systems. The questions are categorized by type: information need (method, dataset, result, task, etc.), reasoning requirement (extractive, abstractive, comparative, enumerative), and difficulty level. The dataset includes answers with supporting evidence spans from the papers.

The comprehensive question taxonomy enables fine-grained evaluation of system capabilities across different question types. The evidence span annotations enable evaluation of answer grounding and citation accuracy.
