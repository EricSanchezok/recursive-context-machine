## Method Description

This paper combines traditional NLP techniques (keyword extraction, topic modeling, named entity recognition) with RAG-based LLM generation for automated literature review. The system first uses NLP pipelines to process a corpus of papers, identifying key topics, entities, and relationships. These structured analyses are then used as context for RAG-based survey generation.

The workflow: (1) Corpus Collection — papers retrieved via keyword search; (2) NLP Preprocessing — topic modeling (LDA/BERTopic), named entity recognition, and keyword extraction identify the conceptual structure of the corpus; (3) Structured Representation — the NLP outputs are organized into a knowledge graph-like representation of themes and relationships; (4) RAG Generation — an LLM generates survey sections using the structured representation as context, with citations to original papers.

The hybrid NLP+RAG approach combines the interpretability of traditional NLP methods with the generative capabilities of LLMs. The structured representation provides a more reliable foundation for generation than raw paper text, reducing hallucination risk.

## Category Rationale

The system uses a single LLM with an NLP preprocessing pipeline. There is no multi-agent coordination, iterative refinement, or user interaction. The contribution is the hybrid NLP+RAG approach, not a novel architectural pattern.

## Limitations

- No citation graph awareness — relies on topic modeling and keyword search
- Single-pass with no refinement
- NLP preprocessing quality depends on corpus completeness
- Topic modeling may miss nuanced connections between papers
