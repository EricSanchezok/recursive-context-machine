## Method Description

This paper describes the Semantic Scholar Open Data Platform, the successor to S2ORC, providing access to 200M+ papers with structured text, embeddings, and citation graph data. The platform offers: (1) bulk data dumps of paper metadata, citation links, and author information, (2) precomputed paper embeddings using SPECTER, (3) structured parsed text (titles, abstracts, bodies, bibliography sections), and (4) API access for real-time querying.

The open data platform enables researchers to build citation-aware retrieval systems without needing to construct their own citation graph from scratch. The precomputed embeddings support semantic similarity search, while the citation graph enables graph traversal methods. This infrastructure underpins many survey generation systems that use Semantic Scholar data for retrieval and expansion.
