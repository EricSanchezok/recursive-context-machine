## Description

ReFACT is a benchmark for evaluating scientific confabulation — instances where LLMs generate plausible-sounding but factually incorrect scientific claims. The dataset contains 1,001 expert-annotated pairs of correct and confabulated scientific claims across multiple disciplines.

Each pair consists of a correct claim (verified against the scientific literature) and a confabulated version that sounds plausible but is factually wrong. The task is to distinguish between correct and confabulated claims, testing the model's ability to recognize when it lacks knowledge or is generating unsupported content.

ReFACT is directly relevant to survey generation factuality evaluation because confabulation — making up plausible-seeming claims with false citations — is a known failure mode of automated survey systems. The benchmark provides test data for evaluating survey system's claim verification capabilities.
