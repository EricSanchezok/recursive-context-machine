## Description

TRUE (The Rational Unified Evaluation) is a meta-evaluation framework for factual consistency metrics. It aggregates 11 established factual consistency datasets spanning summarization, QA, and dialogue, standardizing them under a common evaluation protocol. The benchmark evaluates automatic metrics (e.g., BLEU, ROUGE, BERTScore, NLI-based) against human judgments of factual consistency.

The paper provides: (1) A standardized collection of 11 factuality datasets with unified annotation schemas; (2) Systematic comparison of automatic metric performance across tasks; (3) Analysis of which metric types correlate best with human factual consistency judgments. Findings show that NLI-based metrics consistently outperform overlap-based metrics (ROUGE, BLEU) for factual consistency evaluation.

TRUE is relevant to survey generation because it establishes the evaluation methodology for factual consistency verification, a key quality dimension for automated surveys. The finding that NLI-based metrics outperform lexical overlap metrics is widely cited.
