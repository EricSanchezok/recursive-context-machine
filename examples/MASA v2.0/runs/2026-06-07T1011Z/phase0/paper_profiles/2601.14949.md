## Description

CiteRAG is the first comprehensive RAG benchmark specifically designed for evaluating academic citation prediction. It provides multi-level retrieval tasks: given a claim or statement, the system must retrieve the correct paper(s) that should be cited in support. The benchmark covers multiple difficulty levels from simple attribution (which paper supports this specific finding?) to complex synthesis (which papers jointly support this broader claim?).

CiteRAG includes: (1) A dataset of citation-context pairs extracted from published papers; (2) Multi-level retrieval difficulty (single citation, multiple citation, integrative citation); (3) Evaluation metrics for citation precision, recall, and F1; (4) Baseline results for standard retrieval methods (BM25, DPR, and LLM-based).

The benchmark directly addresses a key challenge in automated survey generation: accurately citing papers for specific claims. It evaluates the retrieval component's ability to find correct citations rather than the generation component's ability to write text.
