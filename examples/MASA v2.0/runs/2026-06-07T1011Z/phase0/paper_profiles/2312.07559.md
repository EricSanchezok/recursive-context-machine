## Description

PaperQA is a foundational RAG agent for scientific research that retrieves papers from Semantic Scholar, extracts relevant passages, and generates answers with citations. It established the core pattern for scientific RAG agents that many later systems build upon.

The architecture: (1) Paper retrieval from Semantic Scholar using keyword and author queries; (2) Passage retrieval using dense embeddings over retrieved paper full texts; (3) Context assembly — top-k passages are assembled as context; (4) Answer generation with inline citations to specific passages; (5) Optional follow-up querying for iterative refinement.

PaperQA demonstrated the feasibility of citation-grounded answer generation from scientific literature. While evaluated primarily on QA tasks, the architecture directly informs survey generation systems that need to retrieve and cite papers.
