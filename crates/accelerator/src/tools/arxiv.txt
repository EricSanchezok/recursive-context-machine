Search academic papers on arXiv or download a paper PDF.

### search — Search arXiv papers

Returns paper metadata: title, authors, categories, abstract, arXiv ID, links.

Parameters:
- `query`: Natural language search query. Required.
- `authors`: Optional, comma-separated author names (OR logic).
- `categories`: Optional, comma-separated categories like `cs.AI,cs.LG` (OR logic).
- `startDate`: Optional start date (YYYY-MM-DD, inclusive).
- `endDate`: Optional end date (YYYY-MM-DD, inclusive).
- `titleKeywords`: Optional, comma-separated title keywords (AND logic).
- `topK`: Number of results (1-100, default 10).

### download — Download an arXiv paper PDF

Downloads the paper PDF to a local file and returns the file path.

Parameters:
- `id`: arXiv paper ID, e.g. `2401.12345` or `hep-th/9901001`. Required.
- `downloadDir`: Directory to save into (default: project root).
- `overwrite`: Overwrite if exists (default: false).
