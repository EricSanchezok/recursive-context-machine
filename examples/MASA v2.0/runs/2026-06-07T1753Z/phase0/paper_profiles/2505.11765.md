## Method Description

OMAC proposes an optimization framework for LLM-based multi-agent collaboration with five optimization dimensions: (1) agent composition — which agents are needed and how they are configured, (2) communication topology — how agents exchange information, (3) task decomposition — how complex tasks are split into subtasks, (4) reasoning strategy — how agents reason individually and collectively, and (5) feedback mechanism — how agents evaluate and improve their outputs.

The framework introduces a joint optimization algorithm that searches across these dimensions to find optimal configurations for a given task. Rather than proposing a specific multi-agent architecture, OMAC provides a methodology for systematically exploring the design space of multi-agent systems. This is applicable to designing survey-generation agents where the optimal configuration may depend on the topic, domain, and quality requirements.

## Category Rationale

OMAC is an optimization framework for designing multi-agent systems, not a multi-agent system itself. It provides methodology for exploring the design space. It does not fit the multi-agent category as it is a meta-framework rather than an operating system.

## Limitations

- Optimization framework, not a deployed system
- Joint optimization across five dimensions may be computationally expensive
- Requires task-specific evaluation metrics for optimization
- Does not provide default configurations — requires tuning per application
