## Method Description

SurveyGen-I introduces a coarse-to-fine retrieval strategy combined with memory-guided writing to produce consistent surveys across subsections. The system addresses a key weakness of sequential section generation — that later sections may contradict or be inconsistent with earlier ones — by maintaining a persistent memory of claims, citations, and positions established in previous sections.

The architecture has three phases. First, Coarse Retrieval casts a wide net to gather a broad paper corpus on the survey topic using hybrid search and citation graph traversal. Second, Plan Evolution generates an initial outline, then refines it iteratively as more papers are analyzed — the outline evolves from coarse topics to fine-grained subsections. Third, Memory-Guided Writing generates each section with access to a shared memory buffer containing key claims and citations from previously written sections, ensuring consistency and reducing redundancy.

The coarse-to-fine retrieval means that initial retrieval is broad (many papers, low precision), and subsequent targeted re-retrieval fills specific gaps identified during plan evolution. The memory-guided writing is distinguished from simple concatenation of sections by enforcing cross-references and consistent terminology across the entire survey.

## Key Innovations

- Coarse-to-fine retrieval strategy that starts broad and refines with targeted re-retrieval
- Memory-guided writing maintaining cross-section consistency via shared claim/citation buffer
- Evolving plan that adapts to paper content rather than fixing the outline before retrieval

## Category Rationale

SurveyGen-I uses a single LLM with a memory mechanism and plan evolution loop. The architecture is sequential: coarse retrieval → plan generation → plan evolution → memory-guided drafting. There are no specialized agents — the memory is a data structure, not a separate agent. The iterative plan evolution adds refinement, but the core architecture is single-agent.

## Limitations

- No citation graph traversal — retrieval is entirely search-based, missing citation chain discoveries
- Single LLM for all stages limits diversity of perspective
- Memory buffer maintains consistency but cannot revise earlier sections to align with later findings
- No explicit quality evaluation loop — refinement is guided by plan evolution, not quality scores
