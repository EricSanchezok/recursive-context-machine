## Description

FActScore introduces atomic factuality evaluation for long-form text, decomposing generated text into atomic facts and verifying each claim individually against a knowledge source. An "atomic fact" is a single, verifiable piece of information that cannot be further subdivided without losing meaning.

The evaluation process: (1) Decompose generated text into atomic facts using an LLM; (2) For each atomic fact, determine whether it is supported by a reference knowledge source; (3) Compute FActScore as the proportion of supported atomic facts. The approach provides interpretable, fine-grained factuality assessment.

FActScore has become the de facto standard for factuality evaluation in survey generation, cited by virtually every survey generation paper that evaluates factuality. It provides a reliable signal for whether generated surveys make claims that are actually supported by cited references.
