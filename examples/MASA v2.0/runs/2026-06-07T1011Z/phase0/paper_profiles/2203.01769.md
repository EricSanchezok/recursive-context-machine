## Description

PeerSum is a dataset for meta-review summarization — generating a consensus summary from multiple peer reviews of the same paper. It contains 15K meta-reviews paired with their constituent reviews from top ML conferences (NeurIPS, ICML, ICLR).

The dataset includes: (1) 15K meta-reviews with constituent peer reviews; (2) Reviewer disagreement instances where reviewers provide conflicting assessments; (3) Structured meta-review targets covering recommendation, strengths, weaknesses, and discussion. The summarization task requires synthesizing potentially conflicting review perspectives into a balanced meta-review.

PeerSum is relevant for survey generation because meta-review synthesis (synthesizing multiple perspectives on the same paper) is a microcosm of survey generation (synthesizing multiple papers on a topic).
