## Description

Multi-XScience is a dataset for generating related-work sections by synthesizing information from multiple cited papers. Each instance consists of a target paper's related-work section (as reference) and the papers it cites (as source).

The dataset includes: (1) 30,000+ instances of related-work sections paired with their cited papers; (2) Full-text of cited papers as source material; (3) Multi-document summarization evaluation framework. The benchmark evaluates systems on their ability to synthesize coherent, well-cited related-work sections from multiple source papers.

Multi-XScience established the related-work generation task as a benchmark for multi-document scientific summarization. It directly evaluates citation-aware text generation, a core capability for survey generation systems.
