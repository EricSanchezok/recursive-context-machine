## Description

ContraDoc is a dataset for detecting self-contradictory statements within long documents. It contains annotated instances where a single document makes claims that are logically inconsistent with each other, even when each claim individually is supported.

The dataset includes: (1) Long-document pairs (full papers, reports) with annotated intra-document contradictions; (2) Contradiction spans identifying the conflicting statements; (3) Contradiction type labels (e.g., factual contradiction, logical inconsistency, numerical discrepancy). Evaluation measures a system's ability to detect when a document contradicts itself.

ContraDoc is relevant for survey generation quality control — generated surveys should be internally consistent, with claims in one section not contradicting claims in another.
