## Method Description

XSum presents a modular RAG pipeline for scientific multi-document summarization with three stages: (1) Ask — dynamic question generation that decomposes a broad topic into specific research questions, (2) Retrieve — targeted retrieval for each generated question using embedding search over a scientific paper corpus, and (3) Summarize — a synthesis module that produces a coherent summary by integrating retrieved evidence across questions. An optional editor module performs refinement and coherence checking on the generated summary.

The modular design allows each stage to be independently configured and optimized. The question generation stage ensures comprehensive coverage by explicitly targeting different aspects of the topic. The retrieval stage benefits from the focused nature of the generated questions, retrieving more relevant content than a single monolithic query. The summarization stage integrates multi-document evidence with citation attribution to support verifiability.

## Category Rationale

XSum operates as a sequential pipeline (Ask → Retrieve → Summarize) driven by a single LLM orchestrating each stage. Despite having multiple stages, it is a single-agent pipeline where one model handles all reasoning steps sequentially rather than multiple specialized agents coordinating. This places it in the single_agent_pipeline category.

## Limitations

- No citation graph traversal — misses structural relationships between papers
- Single-pass generation without iterative improvement
- Question decomposition quality limits downstream retrieval and synthesis
- Does not address temporal bias or citation recency in retrieval
