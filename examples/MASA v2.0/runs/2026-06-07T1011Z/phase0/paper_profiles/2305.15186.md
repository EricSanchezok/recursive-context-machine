## Description

SciReviewGen is a large-scale dataset for automatic generation of scientific literature reviews, containing over 10,000 structured reviews paired with 690,000 cited papers. Each review is a meta-review that synthesizes findings from multiple cited papers, written by domain experts.

The dataset construction: (1) 10,000+ reviews are collected from academic papers across multiple disciplines; (2) Each review is paired with the full text of all papers it cites (690K total); (3) Reviews are structured as multi-paragraph narrative with inline citations; (4) The data supports both extractive and abstractive review generation evaluation.

SciReviewGen was the largest dataset of its kind at publication and enabled training and evaluation of review generation systems. It established the standard format for review generation datasets: target review text paired with source papers.
