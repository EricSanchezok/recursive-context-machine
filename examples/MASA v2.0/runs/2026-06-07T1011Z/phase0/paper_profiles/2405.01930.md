## Description

OARelatedWork is a large-scale dataset for related-work generation containing 94K paper pairs with full-text content. Each instance consists of a target paper's related-work section and the full text of its cited papers, providing much richer source material than abstract-only datasets.

The dataset is constructed from Open Access papers and includes: (1) 94K related-work sections with complete source paper full texts; (2) Cross-domain coverage across multiple scientific disciplines; (3) Full-text access enabling paragraph-level citation analysis; (4) Evaluation framework for both generation quality and citation accuracy.

The large scale (94K instances vs Multi-XScience's 30K) and full-text access make OARelatedWork a more comprehensive resource for training and evaluating citation-aware generation systems for surveys.
