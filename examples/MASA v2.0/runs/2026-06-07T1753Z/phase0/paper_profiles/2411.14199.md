## Method Description

OpenScholar is a retrieval-augmented LM system for literature synthesis that uses a 45M paper datastore and achieves performance where an 8B model beats GPT-4o by 5% on ScholarQABench. The system: (1) builds a comprehensive datastore of 45M scientific papers with precomputed embeddings, (2) retrieves relevant passages via embedding similarity, (3) synthesizes answers with citation attribution, and (4) provides verifiable evidence for each claim.

The key architectural innovation is the scale of the datastore (45M papers) combined with an efficient retrieval pipeline that enables real-time synthesis. The system demonstrates that a well-designed RAG system with comprehensive coverage can outperform much larger models (8B vs GPT-4o) on literature-based tasks.

## Category Rationale

OpenScholar operates as a single RAG pipeline with a large-scale datastore. Despite the scale, it is a single-agent system without multi-agent coordination.

## Limitations

- No citation graph traversal — relies on embedding similarity only
- Datastore of 45M papers may not cover all domains equally
- Single-pass retrieval without iterative expansion
- Focused on QA, not comprehensive survey generation
