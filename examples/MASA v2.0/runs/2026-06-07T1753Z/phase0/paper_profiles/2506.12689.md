## Method Description

SciSage is a multi-agent framework for survey generation with a "reflect-when-you-write" approach, achieving +32% citation F1 on the SurveyScope benchmark. The framework uses multiple specialized agents: (1) a Searcher agent retrieves relevant papers, (2) a Writer agent drafts sections, (3) a Reflector agent evaluates the draft against the retrieved papers for accuracy and coverage, and (4) a Refiner agent revises based on reflection feedback.

The "reflect-when-you-write" design means reflection happens during writing rather than after — the Writer pauses periodically to receive reflection feedback and adjust before continuing. This prevents the accumulation of errors that would be harder to fix in a post-hoc revision stage. The +32% citation F1 improvement indicates significantly better citation accuracy than baselines.
