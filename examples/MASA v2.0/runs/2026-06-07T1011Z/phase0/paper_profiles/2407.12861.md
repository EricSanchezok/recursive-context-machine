## Description

CiteME is a benchmark for evaluating the citation attribution capabilities of LLMs. It presents LLMs with scientific claims and asks them to provide appropriate citations, then evaluates whether the provided citations correctly support the claims. Human performance on the same task is 69.7%, while the best LLM achieves only 18% at the time of publication.

The benchmark includes claims from published papers with expert-verified correct citations. Evaluation measures: citation precision (are cited papers relevant?), citation recall (are all relevant papers cited?), and correctness (do the cited papers actually support the claim?). The paper also introduces CiteAgent, a system that uses retrieval and verification to improve LLM citation accuracy.

CiteME is directly relevant to survey generation evaluation because citation accuracy is a key quality dimension for automated surveys. The large gap between human and LLM performance highlights the challenge of citation attribution.
