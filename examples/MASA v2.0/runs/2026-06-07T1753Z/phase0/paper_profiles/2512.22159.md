## Method Description

Oignon is an open-source tool for exploring citation graphs using a dual-path ranking algorithm with recency weighting. The tool presents an interactive interface where users can start from a seed paper and explore its citation network both forward (papers that cite the seed) and backward (papers the seed cites). The ranking algorithm combines two signals: relevance to the seed paper (measured via textual or embedding similarity) and recency weighting that can be tuned to prefer newer or older publications.

The exploration paradigm is "onion-like" — users peel layers of the citation graph iteratively, expanding outward from a seed set through successive citation hops. Each layer reveals new papers ranked by a configurable blend of relevance and recency. Oignon is designed as a practical exploration tool rather than a survey generation system, providing researchers with a way to discover literature through graph traversal with customizable bias controls.

## Category Rationale

Oignon is a citation graph exploration tool with dual-path ranking and recency weighting. It enhances retrieval through structured graph traversal with configurable bias parameters. It does not generate surveys or use LLM agents, placing it in the graph_enhanced_retrieval category.

## Limitations

- Lacks automated survey synthesis capabilities — it is a discovery/exploration tool only
- Recency weighting is user-configurable but not dynamically optimized
- Does not integrate LLM-based reasoning or summarization
- Scalability to very large citation graphs is not clearly addressed
