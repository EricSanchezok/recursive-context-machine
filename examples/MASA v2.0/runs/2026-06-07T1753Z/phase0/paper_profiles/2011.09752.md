## Method Description

This paper proposes a hybrid learning approach combining learning-to-rank with relevance feedback for technology-assisted systematic literature reviews. The pipeline: (1) initial retrieval using keyword search, (2) learning-to-rank model trained on initial relevance judgments, (3) re-ranking of the paper pool using the trained model, (4) user relevance feedback on top-ranked papers, and (5) iterative retraining and re-ranking.

The hybrid approach leverages both supervised learning (learning-to-rank from labeled data) and interactive learning (user feedback for iterative improvement). This combines the scalability of automated ranking with the accuracy of human judgment.
