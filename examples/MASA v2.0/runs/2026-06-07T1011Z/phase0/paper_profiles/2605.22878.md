# Paper Profile: SciAtlas: A Large-Scale Knowledge Graph for Automated Scientific Research

- **arXiv ID**: 2605.22878
- **Authors**: Shuofei Qiao, Yunxiang Wei, Jiazheng Fan, Bin Wu, Busheng Zhang, Mengru Wang, Yuqi Zhu, Ningyu Zhang, Keyan Ding, Qiang Zhang, Huajun Chen
- **Year**: 2026

## Method Description

SciAtlas is a large-scale, multi-disciplinary, heterogeneous academic knowledge graph designed as a panoramic scientific evolution network. It integrates over 43M papers from 26 disciplines, totaling 157M entities and 3B triplets. The key contribution is providing a structured topological cognitive substrate that dismantles disciplinary barriers and furnishes AI agents with a global perspective for automated scientific research.

The paper explicitly critiques existing retrieval methods: "Current academic retrieval tools predominantly rely on superficial keyword matching or vector-space semantic retrieval, which lack the topological reasoning capabilities required to navigate complex logical connections." This directly identifies the fundamental barrier to multi-hop citation reasoning — existing tools lack the graph infrastructure to support it.

## Architecture

SciAtlas develops a neuro-symbolic retrieval algorithm featuring:
- **Tri-path collaborative recall**: Combines semantic embedding similarity, citation graph topology, and knowledge graph entity linking
- **Graph reranking**: Re-ranks retrieved results using graph-structural features
- **43M papers, 157M entities, 3B triplets** across 26 disciplines

The system supports downstream tasks including literature review, automated research trend synthesis, idea positioning, and academic trajectory exploration.

## Key Innovations
- Massive scale KG (43M papers, 26 disciplines) as infrastructure for reasoning
- Explicit identification that current retrieval (keyword + embedding) lacks topological reasoning
- Neuro-symbolic retrieval combining semantic, citation, and entity-aware pathways
- Explicit support for automated scientific research pipeline

## Method Category
**Knowledge Graph Infrastructure** — This paper provides the graph infrastructure needed to enable multi-hop citation reasoning. It identifies that the current limitation is not just algorithmic but infrastructural: existing retrieval systems do not model the topological structure needed for reasoning across citation chains.

## Relevance to Knowledge Gap
Directly addresses the §4.2 knowledge gap: "Why is multi-hop citation reasoning hard?" The paper provides evidence that:
1. Current tools rely on superficial keyword/embedding retrieval — no topological reasoning
2. Building the graph infrastructure (43M papers, 26 disciplines, 3B triplets) is a significant engineering challenge
3. The field needs neuro-symbolic approaches that combine semantic retrieval with graph reasoning
4. Even at this massive scale, the KG enables but does not fully solve multi-hop reasoning — relevance filtering per hop remains challenging
