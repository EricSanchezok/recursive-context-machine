## Description

CRUISE-Screening is a toolbox for living (continuously updated) systematic literature reviews. It provides automated screening, data extraction, and synthesis update capabilities, enabling SLRs to stay current as new publications emerge.

The toolbox includes: (1) Automated screening using NLP classifiers; (2) Semi-automated data extraction; (3) Living update mechanisms that detect new relevant publications and integrate them into the existing review; (4) Visual analytics for review progress monitoring.

The living review capability is particularly relevant for survey generation systems that aim to produce up-to-date surveys. CRUISE-Screening demonstrates the workflow for continuously integrating new papers into an existing review structure.
