## Method Description

CiteSee is a system that augments inline citations with persistent and personalized historical context, providing readers with relevant background information about cited papers without leaving the reading flow. When a user encounters a citation, CiteSee retrieves and displays contextual information about the cited paper: its key findings, methodology, and relationship to the current paper.

The architecture: (1) Citation Context Extraction — for each citation in a paper, CiteSee extracts the citing context and identifies the cited paper; (2) Historical Context Retrieval — CiteSee retrieves previously stored interactions, annotations, and contextual information about the cited paper from the user's personal knowledge base; (3) Persistent Context Database — maintains a user-specific database of paper interactions, annotations, and relevance assessments that grows over time; (4) Context Presentation — displays relevant historical context inline with the citation.

While CiteSee is designed for reading assistance rather than survey generation, its persistent citation context database and personalized relevance tracking are directly applicable to survey generation systems that need to maintain consistent citation descriptions across a survey.

- Persistent citation context database for historical reference
- Personalized relevance tracking per user
- Inline citation augmentation without disrupting reading flow

## Method Category

single_agent_pipeline

## Category Rationale

CiteSee is a single-agent system for citation context augmentation. It processes citations serially with no multi-agent coordination or iterative refinement.

## Limitations

- Designed for reading assistance, not survey generation
- Requires building a persistent user context database over time
- Cold-start problem — no context available for new users or new papers
- Citation graph awareness not used
