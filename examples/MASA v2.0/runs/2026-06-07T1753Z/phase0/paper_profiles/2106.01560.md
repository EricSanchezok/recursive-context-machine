## Method Description

CitationIE leverages citation graph structure to improve scientific information extraction. The key insight is that papers citing each other often describe related entities, methods, and datasets, so citation relationships provide useful inductive bias for IE. The model uses a GNN that processes both the text of a target paper and the citation graph neighborhood to classify entities and extract relationships.

Information extracted from one paper can propagate through the citation graph: if Paper A extracts "BERT" as a method and Paper B cites A, the system uses this signal to more confidently identify "BERT" in Paper B's text. This citation-aware IE improves extraction accuracy by leveraging the collective signal across the citation graph.

## Category Rationale

CitationIE uses the citation graph to enhance information extraction by propagating entity information across citing-cited paper pairs. The graph structure provides the key inductive bias, making it graph_enhanced_retrieval.

## Limitations

- Information propagation quality depends on citation graph accuracy
- Entity extraction errors may propagate through the graph
- Requires citation graph coverage for all target papers
- Focused on IE, not survey generation or retrieval
