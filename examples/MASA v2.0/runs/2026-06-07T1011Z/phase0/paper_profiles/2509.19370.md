## Method Description

Meow proposes a metadata-driven approach to survey outline generation, where paper metadata (titles, abstracts, keywords, publication venues, citation counts) is used to automatically generate structured survey outlines before any full-text reading occurs. The system extracts metadata from a corpus of retrieved papers and uses it to identify thematic clusters, key research directions, and temporal trends.

The workflow: (1) Paper metadata is collected via search API queries; (2) LLM-based analysis clusters papers by topic, method, and contribution type using only metadata fields; (3) A hierarchical outline is generated with sections organized around identified clusters; (4) The outline is refined by cross-referencing metadata patterns (e.g., citation trends indicating emerging topics). The generation phase then fills in content using full papers as needed.

Meow's insight is that metadata alone provides sufficient signal to produce high-quality outlines, reducing the need for costly full-text processing during the planning stage. This makes it suitable for scenarios where full-text access is limited or where rapid outline prototyping is needed.

## Architecture

- agent_count: 1 (single LLM for metadata analysis and outline generation)
- coordination_pattern: "metadata analysis → outline generation (no writing beyond outline)"
- retrieval_method: "keyword (metadata-only retrieval via search APIs)"
- citation_graph_awareness: "none"
- citation_graph_detail: "not used — works with paper metadata, not citation graph"
- iteration_strategy: "single_pass (no refinement beyond metadata patterns)"

## Key Innovations

- Metadata-only outline generation reducing need for full-text processing
- Metadata pattern analysis for identifying research clusters and trends
- Lightweight approach suitable for rapid prototyping

## Method Category

## Category Rationale

Meow uses a single LLM to analyze paper metadata and generate outlines. The pipeline is sequential and single-pass. The contribution is the metadata-only approach, not the architectural pattern.

## Limitations

- Outline generation only — does not produce full survey text
- No citation graph awareness — entirely dependent on search API metadata quality
- Metadata-only analysis may miss important connections only visible in full text
- No iterative refinement or quality checking
