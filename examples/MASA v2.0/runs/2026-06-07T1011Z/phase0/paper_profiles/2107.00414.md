## Description

MultiCite is a dataset and benchmark for multi-sentence, multi-label citation analysis. It provides annotated citation contexts where each citation mention is labeled with multiple functions (e.g., background, method, result, comparison) spanning multiple sentences.

The dataset includes: (1) 4,206 citation contexts with multi-label function annotations; (2) Multi-sentence spans capturing the full context of each citation; (3) A taxonomy of citation functions based on prior work (SciCite, ACL-ARC). The benchmark evaluates systems on multi-sentence citation context analysis.

MultiCite is relevant for survey generation systems that need to understand citation functions for appropriate citation placement and attribution in generated surveys.
