# Paper Profile: A Reproducible, Scalable Pipeline for Synthesizing Autoregressive Model Literature

- **arXiv ID**: 2508.04612
- **Authors**: Faruk Alpay, Bugra Kilictas, Hamdi Alakkad
- **Categories**: cs.IR, cs.DL, cs.LG
- **Year**: 2025

## Method Description

This paper presents a fully open-source, reproducible pipeline that automatically retrieves candidate documents from public repositories, filters them for relevance, extracts metadata, hyper-parameters and reported results, clusters topics, produces retrieval-augmented summaries, and generates containerised scripts for re-running selected experiments. 

The pipeline demonstrates that reproducibility in automated literature synthesis is achievable: quantitative evaluation on 50 manually-annotated papers shows F1 scores above 0.85 for relevance classification, hyper-parameter extraction, and citation identification. Experiments on corpora of up to 1000 papers demonstrate near-linear scalability with eight CPU workers.

Three case studies confirm faithful reproduction: AWD-LSTM on WikiText-2, Transformer-XL on WikiText-103, and an autoregressive music model on the Lakh MIDI dataset — achieving test perplexities within 1-3% of the original reports.

## Architecture
- **Retrieval**: Automatic candidate document retrieval from public repositories (arXiv, Semantic Scholar)
- **Filtering**: Relevance classification with F1 > 0.85
- **Metadata extraction**: Hyper-parameters, results, abstracts
- **Topic clustering**: Automatic topic discovery from retrieved corpus
- **Summary generation**: Retrieval-augmented summaries per topic cluster
- **Reproduction**: Containerised scripts for re-running experiments from extracted hyper-parameters

## Key Innovations
- First fully open-source, reproducible pipeline for automated literature synthesis
- Achieves near-linear scalability (1000 papers with 8 CPU workers)
- Demonstrates faithful reproduction within 1-3% of original results
- Explicitly addresses the reproducibility gap in automated literature review

## Method Category
**Reproducible Infrastructure** — This paper is not a survey generation system per se, but an infrastructure paper that demonstrates reproducibility is achievable in the literature synthesis space. It serves as evidence for the §6 reproducibility gap: if this pipeline can achieve reproducibility with open-source code, the fact that no ASG system does so is a genuine methodological weakness.

## Relevance to Knowledge Gap
Directly addresses the §6 knowledge gap: "Reproducibility and computational cost blindness in ASG." The paper provides:
1. Existence proof that reproducible literature synthesis is achievable
2. Evidence that relevance classification and metadata extraction can exceed F1>0.85
3. Near-linear scalability demonstration (1000 papers, 8 CPU workers)
4. Contrast: no ASG system (AutoSurvey, ARISE, SciSage, etc.) provides comparable reproducibility infrastructure
