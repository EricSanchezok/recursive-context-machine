## Description

OpenScholar is a specialized RAG system for scientific literature, comprising a retriever trained on 45 million scientific papers and a language model fine-tuned for scientific query answering. The system achieves state-of-the-art citation accuracy by training both the retriever and generator components on scientific domain data.

The architecture: (1) Specialized Retriever — trained on 45M scientific papers using contrastive learning to retrieve relevant passages for scientific queries; (2) Fine-tuned Generator — a language model fine-tuned on scientific text with citation supervision, learning to produce text with accurate inline citations; (3) Citation Verification — post-hoc verification that generated citations match the retrieved context; (4) Multi-document Synthesis — ability to synthesize findings across multiple retrieved papers.

OpenScholar's specialized training on scientific domain data gives it advantages over general-purpose models for scientific literature tasks. The citation-supervised fine-tuning directly addresses the common failure mode of hallucinated or inaccurate citations.
