## Description

SciTLDR is a dataset for extreme summarization of scientific papers, generating one-sentence TLDR summaries capturing the paper's core contribution. It contains 5,400 TLDR summaries for 3,200 papers across CS and biomedical domains.

The dataset establishes a single-sentence summary format where the TLDR captures: (1) The paper's main contribution or finding; (2) The methodology or approach; (3) Key results. TLDRs are written by domain experts from the paper's abstract and introduction.

While TLDRs are much shorter than survey sections, the task of distilling a paper's core contribution into a concise summary is a basic building block for survey generation — survey systems must extract and represent individual paper contributions before synthesizing them.
