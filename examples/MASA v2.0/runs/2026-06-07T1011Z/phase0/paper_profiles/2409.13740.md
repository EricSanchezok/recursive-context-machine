## Description

PaperQA2 is a RAG agent for scientific literature that achieves superhuman performance on scientific synthesis tasks. It extends the original PaperQA with improved retrieval, citation accuracy, and explicit contradiction detection across sources.

The architecture: (1) Paper retrieval via hybrid search (keyword + embedding) over a large scientific corpus; (2) Context retrieval — retrieving specific passages from relevant papers; (3) Claim extraction and verification — extracting atomic claims from generated text and verifying them against source papers; (4) Contradiction detection — identifying and highlighting conflicting claims across different papers; (5) Answer synthesis — generating answers with inline citations.

PaperQA2's superhuman performance was demonstrated on multiple scientific QA benchmarks, where it outperformed human PhD-level scientists at answering scientific questions from literature. The contradiction detection capability is particularly relevant for survey generation, where synthesizing conflicting findings is a key challenge.

## Limitations
