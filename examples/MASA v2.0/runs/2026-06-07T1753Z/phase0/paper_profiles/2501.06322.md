## Method Description

This paper presents a comprehensive survey of multi-agent collaboration mechanisms in the context of LLMs. It provides a taxonomy covering four dimensions: (1) actors — the types of agents (specialized roles, generalists, critics), (2) collaboration types — cooperation, coordination, negotiation, and delegation patterns, (3) structures — hierarchical, flat, dynamic, and market-based organizational structures, and (4) strategies — communication protocols, shared memory, voting mechanisms, and consensus-building approaches.

The survey analyzes existing multi-agent systems across these dimensions, extracting design patterns and best practices. It covers how agents communicate (structured messages, shared workspaces, blackboard architectures), how they reach consensus (voting, ranking, iterative refinement), and how they adapt to task requirements (dynamic role assignment, agent creation/destruction). This provides a reference framework for designing multi-agent survey systems.
