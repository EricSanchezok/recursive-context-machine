## Method Description

This paper introduces a post-hoc citation generation method for LLM outputs, applicable as a training-free plugin to existing LLM-based chatbots. The system takes an LLM-generated response and adds citations by: (1) decomposing the response into atomic claims; (2) searching a reference corpus for documents supporting each claim; (3) using NLI (natural language inference) to verify that each retrieved document actually supports the claim; (4) attaching verified citations to the response.

The approach is notable for its post-hoc design — it does not require modifying the LLM's generation process or training a custom model. It can be applied to any existing LLM chatbot output. The NLI verification step is critical: it filters out retrieved documents that don't actually support the claim, reducing hallucinated citations.

While designed for chatbot responses, the approach is directly applicable to survey generation: generated survey text can be post-hoc augmented with verified citations. The paper evaluates on multiple datasets and shows significant improvements in citation precision compared to retrieval-only baselines without NLI verification.

- agent_count: 1 (single pipeline for post-hoc citation processing)
- coordination_pattern: "post-hoc pipeline — claim decomposition → retrieval → NLI verification → citation attachment"
- retrieval_method: "keyword/dense (search over reference corpus for each claim)"
- citation_graph_awareness: "none"
- citation_graph_detail: "not used — retrieval is from a flat corpus"
- iteration_strategy: "single_pass (post-hoc processing, no refinement)"

## Key Innovations

- Training-free post-hoc citation plugin applicable to any LLM
- NLI-based claim-citation verification filtering out unsupported citations
- Claim decomposition enabling fine-grained citation attribution

## Method Category

single_agent_pipeline

## Category Rationale

The method is a single pipeline processing LLM outputs post-hoc. There is no multi-agent coordination, no retrieval innovation beyond standard search, and no iterative refinement. The contribution is the verification step (NLI filtering), not the architectural pattern.

## Limitations

- Post-hoc only — cannot guide generation to produce more citable content
- No citation graph awareness
- Claim decomposition quality depends on LLM capability
- NLI verification adds latency and may have false negatives
- Designed for chatbot responses — scaling to long-form survey text may be expensive
