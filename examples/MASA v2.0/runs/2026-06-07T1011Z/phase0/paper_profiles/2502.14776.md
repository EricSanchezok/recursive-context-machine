## Method Description

SurveyX introduces the AttributeTree preprocessing method for survey generation, which organizes the target survey topic into a structured attribute hierarchy before retrieval and writing. An AttributeTree is a multi-level decomposition of a research topic into its constituent attributes — methods, datasets, metrics, applications, challenges — organized hierarchically. This structure serves as both a retrieval plan and an outline template.

The pipeline proceeds in three phases: (1) AttributeTree Construction — the LLM analyzes the topic and generates a structured attribute hierarchy; (2) Online Retrieval — for each leaf attribute in the tree, the system performs targeted search queries to find relevant papers; (3) Re-Polishing — after initial draft generation, the system performs a citation quality enhancement step that verifies citations match their claims and fills missing citations by re-querying.

SurveyX's key innovation is using the AttributeTree to enable fine-grained, attribute-aware retrieval. Rather than retrieving papers for entire sections, each attribute node gets its own targeted retrieval, ensuring balanced coverage across all dimensions of the topic. The re-polishing phase adds a training-free citation quality check that uses NLI-like verification to ensure each citation actually supports the claim it accompanies.

## Key Innovations

- AttributeTree preprocessing for structured topic decomposition and fine-grained retrieval
- Per-attribute targeted retrieval ensuring balanced coverage across topic dimensions
- Training-free citation quality re-polishing with NLI-like claim-citation verification

## Method Category

## Category Rationale

SurveyX uses a single LLM to drive all phases of the pipeline through structured prompting. The AttributeTree is a preprocessing innovation that improves retrieval targeting, but the system architecture is sequential and single-agent. The re-polishing phase adds post-hoc verification but does not create an iterative refinement loop.

## Limitations

- No citation graph traversal — retrieval is entirely attribute-keyword-driven
- Single LLM for all stages limits perspective diversity
- Re-polishing verifies citation-claim alignment but does not discover new relevant papers missed during initial retrieval
- AttributeTree construction quality depends on LLM's understanding of the topic structure
