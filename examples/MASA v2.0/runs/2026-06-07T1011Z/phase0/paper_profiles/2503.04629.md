## Method Description

SurveyForge introduces a memory-driven generation architecture for automated survey writing, with a strong focus on outline quality as the foundation for coherent surveys. The system first performs an extensive analysis of outline heuristics — studying how human-written surveys structure their content — and uses these insights to design a principled outline generation module.

The architecture consists of three main phases. First, the Retrieval Phase gathers papers using keyword and embedding search augmented with citation graph traversal (forward and backward chaining) from seed papers. Second, the Outline Generation Phase uses learned heuristics about section ordering, depth, and topical organization to produce a structured survey outline. Third, the Memory-Driven Generation Phase produces each section using a memory mechanism that maintains cross-section context: as each section is written, key claims and citations are stored in a memory buffer that subsequent sections can reference, ensuring coherence and reducing redundancy.

SurveyForge introduces a multi-dimensional evaluation protocol that measures outline quality, content quality, citation quality, and coherence. The system also contributes SurveyBench (not to be confused with the separate 2510.03120 SurveyBench), a benchmark of 100 human-written surveys used for win-rate comparisons.

## Key Innovations

- Systematic analysis of outline heuristics from human-written surveys informing automated outline generation
- Memory-driven generation that maintains cross-section context to improve coherence
- Multi-dimensional evaluation framework covering outline, content, citation, and coherence
- Citation graph traversal (forward+backward) integrated into retrieval

## Category Rationale

SurveyForge integrates citation graph traversal (forward and backward chaining) into its retrieval phase, making graph awareness a core component of the pipeline. While the generation itself is single-agent, the retrieval strategy explicitly uses citation graph structure to expand paper coverage. The memory-driven generation and outline heuristics are secondary to the graph-enhanced retrieval innovation.

## Limitations

- Single-pass pipeline with no iterative refinement between stages
- Citation graph traversal is uniform (BFS) — no hierarchical organization of discovered papers
- Memory mechanism maintains context but does not enable revision of earlier sections based on later content
- Single LLM drives all stages, limiting ability to incorporate diverse perspectives
