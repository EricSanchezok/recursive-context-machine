## Method Description

AutoSurvey2 is a multi-stage RAG pipeline for automated literature survey generation that extends the original AutoSurvey with parallel section generation and iterative refinement. The pipeline consists of: (1) a planning stage that generates a survey outline with sections and subsections, (2) a retrieval stage that for each section performs targeted literature search using RAG over a scientific corpus, (3) a parallel section generation stage that writes multiple sections simultaneously using separate LLM calls, (4) a consolidation stage that merges sections into a coherent survey, and (5) an iterative refinement stage that improves the survey based on self-evaluation.

The parallel section generation is a key efficiency innovation — rather than writing the survey sequentially, AutoSurvey2 writes sections in parallel and then consolidates them, which both speeds up generation and reduces sequential error propagation. The refinement stage uses a multi-LLM evaluation protocol where different LLM instances evaluate different quality dimensions (coverage, accuracy, readability, citation faithfulness) and the survey is revised based on this feedback.

## Category Rationale

AutoSurvey2 uses multiple specialized LLM instances operating in parallel and in sequence: a planner, retriever, multiple section writers, a consolidator, and a refiner. These roles constitute distinct agents with specialized functions, communicating through their outputs. This division of labor qualifies it as a multi_agent_pipeline.

## Limitations

- No citation graph awareness — relies entirely on semantic retrieval
- Parallel section generation may produce inconsistencies across sections
- Multi-LLM evaluation adds significant computational cost
- Does not address temporal bias or recency of retrieved literature
