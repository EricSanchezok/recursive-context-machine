## Method Description

ReClaim introduces an interleaved reference-claim generation mechanism for RAG systems that generates citations at the sentence level. Rather than generating a block of text and then attaching citations, ReClaim interleaves claim generation with explicit reference retrieval and verification.

The mechanism works as follows: for each sentence to be generated, the system first retrieves relevant reference passages, then generates the claim while explicitly citing the retrieved references, then verifies that the claim is supported by the cited references. This sentence-by-sentence interleaving ensures that every generated claim has a supporting reference, dramatically reducing hallucination rates.

The architecture is implemented as a training-free plugin for existing RAG systems. It adds a retrieval-verify step between each sentence, which increases generation latency but provides fine-grained citation attribution. ReClaim is evaluated on multiple QA and summarization tasks, demonstrating improved citation precision and recall compared to post-hoc citation attachment.

## Architecture

- agent_count: 1 (single LLM with interleaved retrieval-generate-verify loop per sentence)
- coordination_pattern: "sentence-level interleaving — retrieve references → generate claim → verify claim-citation alignment → next sentence"
- retrieval_method: "keyword/dense (retrieval per sentence from reference corpus)"
- citation_graph_awareness: "none"
- citation_graph_detail: "not used — retrieval is from a flat reference corpus"
- iteration_strategy: "multi_round (per-sentence retrieve-generate-verify loop)"

## Key Innovations

- Sentence-level interleaved reference-claim generation ensuring fine-grained citation attribution
- Training-free plugin architecture applicable to any RAG system
- Explicit verification step between claim generation and citation to prevent hallucination

## Method Category

## Category Rationale

ReClaim's core innovation is the per-sentence iterative loop (retrieve → generate → verify) that refines the claim-citation alignment at each step. This sentence-level iterative refinement is a genuine architectural innovation, though it operates at the micro-level (per sentence) rather than the macro-level (per section or per draft).

## Limitations

- Increased latency due to per-sentence retrieval and verification
- Designed for short-form generation (QA, summarization) — scaling to full survey generation may be expensive
- No citation graph awareness — references are from a flat corpus
- Verification step quality depends on LLM's ability to detect claim-reference mismatch
