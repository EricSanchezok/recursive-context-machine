## Method Description

Science Hierarchography introduces a hybrid approach combining embedding-based clustering with LLM reasoning to organize scientific literature into hierarchical structures. The method operates in three stages: (1) paper embeddings are computed using a scientific language model (e.g., SciBERT or SPECTER), (2) these embeddings are clustered at multiple resolution levels using a hierarchical clustering algorithm that produces a tree of topics, and (3) an LLM is prompted to label and refine each cluster, producing human-readable topic descriptions and adjusting cluster boundaries based on semantic reasoning.

The key innovation is the division of labor between embedding similarity (which captures coarse topical relationships) and LLM reasoning (which provides semantic interpretation and refinement). The embedding stage handles large-scale similarity computation efficiently, while the LLM stage provides the conceptual understanding needed for accurate labeling and boundary adjustment. The output is a multi-level hierarchy where each level represents a different granularity of topic organization, from broad fields (top level) to specific research directions (bottom level).

- Scalable by design — embedding clustering handles large corpora efficiently

## Category Rationale

Science Hierarchography organizes scientific literature into hierarchical structures using a hybrid embedding-LLM approach. While it does not directly use citation graph traversal, it produces hierarchical topic taxonomies that can serve as retrieval or planning structures for survey agents. The multi-level hierarchy output is the key graph-like structure, placing it in the graph_enhanced_retrieval category.

## Limitations

- Does not leverage citation graph structure, which could provide complementary organizational signals
- LLM refinement stage may introduce labeling biases or inconsistency across clusters
- Static hierarchy — does not adapt to evolving research landscapes without full recomputation
- Evaluation on standard taxonomy or clustering benchmarks not reported in available metadata
