## Method Description

FAST² (Finding Relevant Papers Fast and Smart) is an intelligent assistant for literature search that uses a self-correcting classifier and an estimator of remaining relevant papers. The system works by: (1) having the user provide an initial seed set of relevant and irrelevant papers, (2) training a text classifier on these seeds, (3) running the classifier on a pool of candidate papers, (4) showing the user the top-ranked candidates for relevance feedback, and (5) iterating to improve the classifier while estimating how many relevant papers remain undiscovered.

The key innovation is the "estimator of remaining relevant papers" — a statistical method that predicts how many more relevant papers exist in the search pool based on the current classifier's performance and the pool size. This helps users decide when to stop searching (once most relevant papers have been found), addressing the stopping criterion problem in systematic literature reviews.

## Category Rationale

FAST² is an interactive system where the user provides relevance feedback to iteratively improve a classifier for literature search. The human-in-the-loop feedback mechanism and the stopping criterion estimator make it a hybrid_interactive method. The user directly guides the search process.

## Limitations

- Pre-dates LLMs; uses traditional text classification (e.g., SVM, Naive Bayes)
- No citation graph awareness — relies entirely on text content
- Requires substantial user effort for relevance feedback
- Estimator accuracy depends on pool size and classifier quality
