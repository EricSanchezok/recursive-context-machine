## Method Description

GEAR-Up introduces a query expansion framework that leverages knowledge graphs to enhance paper retrieval for survey generation. When given an initial topic query, the system expands it using entities and relations from a knowledge graph (e.g., Semantic Scholar's literature graph), generating multiple specific sub-queries that cover different aspects of the topic.

The architecture: (1) Initial Query Analysis — the topic is analyzed to extract key entities; (2) Knowledge Graph Traversal — entities are used to traverse the knowledge graph, identifying related concepts, methods, and sub-fields; (3) Query Expansion — the discovered knowledge graph entities are used to generate expanded queries targeting specific aspects; (4) Multi-Query Retrieval — expanded queries are executed against paper databases; (5) Result Aggregation — retrieved papers are deduplicated and ranked.

The key innovation is the integration of knowledge graphs for query expansion rather than relying solely on LLM-generated expansions. The knowledge graph provides principled, structured query expansion based on established conceptual relationships, potentially discovering papers that pure keyword expansion would miss.

## Category Rationale

GEAR-Up's core contribution is the integration of knowledge graph traversal into the retrieval process. The KG provides structured query expansion that goes beyond keyword matching. This graph-enhanced retrieval clearly distinguishes it from purely search-based approaches.

## Limitations

- Query expansion only — does not address generation quality
- Knowledge graph coverage may have gaps in emerging research areas
- Single-pass with no iterative refinement of the expansion
- Evaluation limited to retrieval metrics — generation quality not assessed
