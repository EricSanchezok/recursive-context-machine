## Method Description

This early RLHF paper applies reinforcement learning to Neural Machine Translation (NMT) using simulated human feedback. The system uses a bandit formulation where the agent generates a translation and receives a simulated quality score as feedback, without access to the reference translation. The policy is optimized to maximize expected feedback using policy gradient methods.

The paper is foundational for RLHF in text generation, demonstrating that RL optimization from quality feedback can improve generation quality even without reference outputs. This methodology is foundational for any RL-based approach to survey generation optimization.

## Limitations

- Domain-specific to NMT, not survey generation
- Uses simulated (not real human) feedback
- Bandit formulation ignores sequential aspects of survey generation
- Pre-dates modern LLMs and preference optimization methods (DPO, etc.)
