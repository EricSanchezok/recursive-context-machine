## Method Description

SurveyBench is a comprehensive benchmark for evaluating automated survey generation systems. It provides a quiz-driven evaluation framework: for each survey topic, there is a set of quiz questions that can only be answered by reading the survey. The benchmark evaluates whether a generated survey provides sufficient information to answer these questions, measuring answerability as a proxy for coverage and quality.

The dataset includes 11,343 arXiv papers and 4,947 human-written surveys across multiple disciplines. Evaluation is organized in a quality hierarchy: outline quality, content quality, and non-textual quality (figures, tables). The benchmark supports both content-based evaluation (comparing generated text to reference) and quiz-based evaluation (testing whether the survey enables readers to answer domain questions).

SurveyBench also introduces dual-mode evaluation: absolute scoring using rubrics and comparative scoring (A vs B win-rate). This provides flexibility for evaluating different types of survey generation systems.

## Category Rationale

## Limitations

- Quiz construction requires domain expertise — quality depends on question design
- Single reference survey per topic may not capture diverse valid survey structures
- Non-textual quality evaluation (figures, tables) is inherently difficult for automated systems
