## Method Description

AutoAgents introduces a framework for automatically generating and adapting agents for different tasks. The framework includes: (1) an agent generator that creates specialized agents based on task requirements, (2) an observer role that monitors agent performance and identifies issues, (3) a task-role coupling mechanism that dynamically assigns agents to tasks based on their capabilities, and (4) a reflection mechanism where agents evaluate their performance and suggest improvements.

The key innovation is the dynamic agent generation — rather than using a fixed set of agents, AutoAgents creates new agents on-demand for specific sub-tasks. The observer agent provides system-level oversight, identifying when agents are failing or when new agent types are needed. The task-role coupling ensures that the right agent type is matched to each sub-task. This adaptive approach is relevant to survey generation where different topics may require different specialized agent configurations.

## Limitations

- Agent generation adds computational overhead
- Observer quality depends on LLM capability for system-level reasoning
- Generic framework — requires task-specific customization for literature survey
- Dynamic agent creation may lead to unpredictable system behavior
