## Narrative Threads

Before writing the outline, identify **2-4 narrative threads** that run across sections.
These are the core argumentative through-lines that make a survey more than a categorized
paper list. Examples:
- "The exploration-exploitation trade-off in citation graph traversal: systems must
  balance breadth of coverage against depth of relevance"
- "The tension between automation and human control: as systems become more autonomous,
  citation precision degrades but scalability improves"
- "The evaluation comparability crisis: every benchmark measures something different,
  making progress unmeasurable"

Each thread should:
- Be grounded in the evolution narrative's Critical Assessment or Claim-vs-Evidence Gap table
- Name the **tension**, **trade-off**, or **unresolved problem** (not just a topic area)
- Touch at least 2-3 sections in the outline

You MUST output the threads in the outline file before the section list. This ensures
the Generator can weave them across subsections during assembly.

## Section Plan Format (write to `memory/section_plan.md`)

After writing the outline, generate a per-subsection writing plan in YAML format. This plan is the Generator's PRIMARY guide.

### Rules

1. **Core vs Non-core**: Sections 2-5 (core methods) should have `depth_level: "deep"` with `target_words: 500-800`. Introduction, Related Work, Conclusion should be `depth_level: "standard"` with `target_words: 200-400`.
2. **Key Papers**: For each subsection, select 3-6 most relevant papers from the candidate pool that match the section's `Reference Papers`.
3. **Writing Instructions**: For deep subsections: "Compare X, Y, Z in a table across relevant dimensions. For each method, explain the mechanism (not just the purpose). Include pros/cons and quantitative results." For standard subsections: "Summarize key works, identify trends."
4. **Dependency Tracking**: Subsections within the same section depend on the previous one. Section 2 subsections depend on Section 1, etc.
5. **Depth Definitions**:
   - `"deep"`: Comparison table required, mechanism-level analysis, pros/cons, quantitative results, 500-800 words
   - `"standard"`: Clear summary with citations, trends identification, 200-400 words
   - `"minimal"`: Brief overview, 100-200 words (only for very minor subsections)

### YAML Format

```yaml
subsections:
  - id: "s1"
    section_number: "1"
    title: "Introduction"
    depends_on: []
    target_words: 300
    key_papers: []
    writing_instructions: "Write a concise introduction covering motivation, scope, contributions, and paper roadmap."
    depth_level: "standard"

  - id: "s2.1"
    section_number: "2.1"
    title: "Single-Agent Architectures"
    depends_on: ["s1"]
    target_words: 600
    key_papers: ["arXiv:2406.10252", "arXiv:2502.14776", "arXiv:2503.04629"]
    writing_instructions: "Compare AutoSurvey, SurveyX, SurveyForge. Include a comparison table with dimensions: approach, key innovation, citation graph usage, limitations. For each method explain HOW the architecture works."
    depth_level: "deep"
```
