## Method Description

DenseReviewer combines dense retrieval with active learning for systematic review screening prioritization. The system uses dense passage embeddings (from models like SPECTER) to rank papers by relevance to the review topic, then applies active learning to iteratively improve ranking based on user feedback. The web-based tool provides an interactive interface for efficient screening.

The dense retrieval provides better initial ranking than keyword-based approaches, reducing the number of papers users need to review. The active learning component adapts to user preferences over time, learning which types of papers are relevant for the specific review.
