## Method Description

This paper proposes and evaluates a zero-shot decomposition protocol for automated literature review using LLMs. The protocol decomposes the review process into three stages — retrieval, planning, and generation — each implemented via zero-shot prompting of an LLM without fine-tuning or specialized training.

The retrieval stage uses LLM-generated keyword extraction from the topic description to formulate search queries, executes them against academic search APIs (Semantic Scholar), and re-ranks results based on relevance. The planning stage uses the retrieved paper set to generate an outline of the review, identifying key themes and groupings. The generation stage produces each section of the review in sequence, citing retrieved papers.

The paper's primary contribution is as an evaluation protocol rather than a novel system. It provides a structured evaluation framework for assessing how well current LLMs perform each stage of the literature review process, identifying specific bottlenecks (particularly in citation accuracy and coverage). The evaluation covers multiple LLMs (GPT-4, Claude, Gemini) and topics, providing a comparative assessment of LLM capabilities for literature review tasks.

- Comparative evaluation across multiple LLMs (GPT-4, Claude, Gemini)

## Category Rationale

The evaluation protocol uses a single LLM with zero-shot prompts across three stages. The architectural approach is sequential and single-agent. The paper's main contribution is the evaluation framework, not a novel generation system.

## Limitations

- Zero-shot only — no training, fine-tuning, or few-shot examples used
- No citation graph awareness — retrieval is entirely search-based
- Single-pass with no refinement
- Evaluation reveals significant gaps in LLM citation accuracy and coverage
