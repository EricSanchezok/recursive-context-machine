## Method Description

Paperfetcher is a tool that automates handsearching for systematic reviews through bidirectional snowballing. Given a set of seed papers, it automatically retrieves both forward citations (papers that cite the seed) and backward citations (papers that the seed cites) from bibliographic databases, iterating through multiple rounds of expansion. The tool is designed to replace the manual handsearch process in systematic reviews, which involves manually checking reference lists and citation lists.

Paperfetcher automates this through API calls to citation databases (e.g., Crossref, PubMed), deduplication of retrieved results, and tracking of the search process for reproducibility. The tool supports configurable expansion depth and can integrate with screening workflows. It predates modern LLM-based survey agents but provides the core citation expansion automation that many current systems build upon.

## Category Rationale

Paperfetcher automates bidirectional citation snowballing for systematic review search. Citation graph traversal (forward and backward) is the core mechanism, making it a graph_enhanced_retrieval tool. It does not generate surveys or use LLMs.

## Limitations

- Pre-dates LLM integration; no semantic understanding or synthesis
- Depends on bibliographic database API availability and coverage
- Retrieved results still require manual screening and synthesis
- No built-in quality assessment or relevance ranking beyond citation relationships
