## Description

MAG-20 is a dataset for topic-centric multi-document summarization across 20 research fields. Using the Microsoft Academic Graph (MAG), it constructs topic-specific document clusters and provides human-written summaries for each cluster.

The dataset: (1) 20 research fields with multiple topic clusters each; (2) Topic-centric document clusters representing coherent research subtopics; (3) Human-written summaries synthesizing each cluster; (4) Unsupervised evaluation framework for topic-centric summarization without requiring reference summaries for every topic.

MAG-20 evaluates multi-document summarization at the topic level, which is more similar to survey section generation than generic multi-document summarization. The topic-centric organization aligns with how surveys organize content by thematic areas.
