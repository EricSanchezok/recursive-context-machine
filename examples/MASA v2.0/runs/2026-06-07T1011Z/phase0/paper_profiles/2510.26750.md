## Description

ProfOlaf combines traditional systematic review methodology (particularly snowballing) with LLM assistance for semi-automated SLR. The system supports both forward and backward snowballing from seed papers, using LLMs to assist with screening, data extraction, and synthesis.

The workflow: (1) Seed paper identification — user provides seed papers; (2) Backward snowballing — following references from seed papers, with LLM-assisted relevance screening; (3) Forward snowballing — finding papers that cite seed papers, again with LLM screening; (4) Iterative snowballing — repeating backward/forward steps to expand coverage; (5) Data extraction and synthesis — LLM extracts structured data and generates narrative synthesis.

ProfOlaf's key contribution is integrating explicit citation snowballing (a core SLR methodology) with LLM assistance. This is one of the few systems that directly implements citation graph traversal following established SLR snowballing protocols.

## Limitations

- Semi-automated — requires user seed paper selection and validation
- Snowballing depth limited by practical constraints (diminishing returns after 2-3 iterations)
- LLM screening quality determines snowballing relevance
- Less emphasis on generation quality compared to dedicated survey writing systems
