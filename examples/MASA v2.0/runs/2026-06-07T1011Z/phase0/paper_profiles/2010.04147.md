## Description

AutoReviewGen is an early system for automatic generation of literature review sections using BERT-based extractive methods, predating the LLM era. The system extracts salient sentences from a set of source papers and assembles them into a coherent review section.

The architecture: (1) Sentence scoring using BERT-based representations to identify the most relevant and salient sentences from source papers; (2) Diversity-aware selection ensuring coverage of different papers and perspectives; (3) Sentence ordering using temporal or thematic criteria; (4) Coherence enhancement through transitional phrase insertion.

As an extractive system, AutoReviewGen produces review text composed entirely of sentences from source papers, avoiding hallucination but limiting the ability to synthesize novel insights across papers.
