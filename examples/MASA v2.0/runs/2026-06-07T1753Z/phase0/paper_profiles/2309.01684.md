## Method Description

CRUISE-Screening is a web-based living literature review toolbox that combines API search with text classification. The system: (1) runs automated API searches against bibliographic databases on a schedule, (2) uses text classification to screen new papers for relevance, (3) allows human validation of screening decisions, and (4) maintains an up-to-date living review that evolves as new papers are published.

The "living" aspect means the review automatically updates as new literature is published, making it suitable for fast-moving fields. The combination of automated screening with human validation provides efficiency without sacrificing quality control.

## Limitations

- Screening-only — does not include synthesis or writing
- API search quality depends on database coverage
- Living update schedule may miss papers published between updates
- Pre-dates modern LLM capabilities for advanced screening
