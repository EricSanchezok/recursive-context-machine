## Method Description

SPECTER (Scientifc Paper Embeddings using Citation-informed TransformERS) is a core citation-informed document embedding method that fine-tunes a Transformer language model using citation graph signals as training data. The key idea: papers that are related via citation should have similar embeddings. SPECTER is trained using a contrastive learning objective where pairs of papers connected by citation edges are pulled together in embedding space while random pairs are pushed apart.

The resulting embeddings capture both semantic content (from the Transformer pre-training) and citation relevance (from the contrastive fine-tuning). SPECTER embeddings have become a standard building block for citation-aware retrieval systems, used for similarity search, clustering, and recommendation. The method is particularly effective for zero-shot and few-shot settings where labeled data is scarce.

## Category Rationale

SPECTER uses the citation graph as a training signal for embedding learning. The graph provides the supervisory signal for contrastive training, making it graph_enhanced_retrieval. SPECTER is one of the most influential methods in this category.

## Limitations

- Embeddings trained once — do not adapt to task-specific requirements
- Citation graph sparsity may limit embedding quality for less-cited papers
- Does not capture temporal dynamics or evolving citation patterns
- Pre-dates more recent embedding methods (SPECTER 2.0, etc.)
