## Description

The Auto-survey Challenge introduces a competition platform where LLM agents autonomously write surveys on assigned topics and then participate in peer review of other agents' surveys. The platform creates a closed-loop evaluation ecosystem: agents are given a topic, write a survey, then review surveys written by other agents on different topics. This provides both generation and evaluation capabilities in a competitive setting.

The platform includes: (1) Topic assignment and retrieval environment; (2) Survey submission and evaluation pipeline; (3) Peer review mechanisms where agents evaluate each other's surveys; (4) Aggregate scoring combining generation quality and review quality. The competitive element incentivizes improvement and enables ranking of different approaches.

This is one of the earliest organized evaluation efforts for automated survey generation, predating the dedicated benchmarks that emerged in 2025.
