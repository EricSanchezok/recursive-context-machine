## Method Description

SWARM-SLR provides a framework for streamlining workflow automation for machine-actionable systematic literature reviews. It synthesizes 65 requirements from existing SLR guidelines (PRISMA, Cochrane, Campbell) and maps 11 existing SLR automation tools to the SLR lifecycle stages. The framework defines how SLR workflows can be structured for machine-actionability — where software tools can automatically execute or assist with each stage.

The analysis reveals gaps in current tool coverage across the SLR lifecycle, particularly in synthesis and reporting stages. The 65 requirements provide a comprehensive specification for what SLR automation tools should support, serving as a design blueprint for developers of SLR automation systems.
