## Method Description

ASReview is an open-source active learning system for efficient systematic review screening. The system uses active learning to prioritize papers for manual screening: (1) a user labels a small number of papers as relevant or irrelevant, (2) a machine learning classifier learns from these labels, (3) the classifier ranks the remaining papers by predicted relevance, (4) the user screens the top-ranked papers, adds their labels, and the classifier is retrained, and (5) this cycle continues until a stopping criterion is met.

The active learning approach dramatically reduces the screening effort — users only need to review a fraction of the total papers to identify most relevant ones. ASReview is designed for the screening stage of systematic reviews, not for survey generation, but the active learning methodology for efficient relevance assessment is relevant.

## Category Rationale

ASReview uses active learning with interactive user feedback for efficient screening. The human provides relevance labels while the AI prioritizes papers, making it a hybrid_interactive system.

## Limitations

- Screening-only — does not include extraction or synthesis
- Requires user effort for labeling each iteration
- Active learning may miss rare but relevant papers
- Pre-dates LLM integration for more sophisticated relevance assessment
