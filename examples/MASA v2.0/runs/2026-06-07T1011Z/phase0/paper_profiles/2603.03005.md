## Description

OrchMAS (Orchestrated Multi-Agent System) introduces a platform for multi-agent scientific expert collaboration in automated research synthesis. The system provides a framework where specialized scientific expert agents (each with domain-specific knowledge and capability profiles) are orchestrated by a coordinator agent to produce research syntheses.

The architecture: (1) Coordinator Agent analyzes the research question and creates a work plan; (2) Expert Agents — each pre-configured with domain expertise (e.g., machine learning, statistics, neuroscience) — are assigned tasks matching their expertise; (3) Expert agents retrieve papers, analyze findings, and produce structured summaries in their domain; (4) Coordinator Agent integrates expert outputs into a coherent synthesis, resolving conflicts and identifying consensus.

The key innovation is the explicit modeling of domain expertise at the agent level. Rather than having all agents operate with general knowledge, OrchMAS assigns domain-specific knowledge bases and capability profiles to each expert agent. This enables more authoritative domain analysis than general-purpose agents.

OrchMAS uses multiple expert agents with domain-specific knowledge orchestrated by a coordinator. This is a genuine multi-agent architecture with role specialization based on domain expertise, distinct from homogeneous agent ensembles.
