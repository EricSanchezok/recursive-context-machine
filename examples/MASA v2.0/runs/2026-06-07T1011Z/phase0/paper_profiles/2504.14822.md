## Method Description

InsightAgent is an LLM-powered system designed to complete systematic literature reviews in hours rather than weeks. It combines automated search, screening, data extraction, and synthesis into an integrated pipeline targeting rapid SLR execution while maintaining methodological rigor.

The system uses: (1) Multi-database search with automated query refinement; (2) LLM-based title/abstract screening with configurable inclusion criteria; (3) Full-text retrieval and data extraction using structured templates; (4) Automated quality assessment; (5) Narrative synthesis generation. The speed comes from parallelizing search and screening across multiple LLM instances and databases simultaneously.

InsightAgent emphasizes transparency and reproducibility — all search strategies, screening decisions, and extraction templates are recorded for audit. The system is evaluated on multiple SLR topics, demonstrating completion times of 4-8 hours for reviews that would typically take 2-4 weeks manually.

## Category Rationale

InsightAgent uses parallel LLM instances for efficiency but does not employ specialized agent roles or multi-agent coordination. Each LLM instance performs the same task (searching, screening) with different inputs. The architecture is a parallelized single-agent pipeline rather than a multi-agent system.

## Limitations

- No citation graph awareness — follows traditional database search
- Parallelization increases computational cost
- Quality assessment limited to configurable criteria — may miss domain-specific quality aspects
- Speed gains may come at the cost of thoroughness compared to multi-pass iterative systems
