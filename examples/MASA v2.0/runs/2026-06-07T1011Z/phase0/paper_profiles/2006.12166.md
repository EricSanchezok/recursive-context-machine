## Description

ASReview is an open-source system using active learning for efficient title/abstract screening in systematic literature reviews. It prioritizes papers by relevance, reducing the screening workload by 90%+ while maintaining recall.

The system uses an iterative active learning loop: (1) The user labels a small set of papers as relevant/irrelevant; (2) A machine learning model (typically Naive Bayes or neural network) learns from these labels; (3) The model predicts relevance scores for all unlabeled papers; (4) The system presents the highest-scoring papers for the user to label; (5) The loop repeats until stopping criteria are met.

ASReview is one of the most widely used SLR tools in the traditional SLR community. While it uses ML rather than LLMs, the active learning paradigm for efficient screening is relevant to LLM-based survey systems that need to filter large paper corpora.

## Category Rationale

ASReview requires human labeling in the loop and uses ML to prioritize screening. The human-in-the-loop active learning distinguishes it from fully automated systems.
