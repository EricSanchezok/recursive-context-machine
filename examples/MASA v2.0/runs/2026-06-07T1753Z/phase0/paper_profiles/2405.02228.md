## Method Description

REASONS provides sentence-level citation attribution annotations across 12 scientific domains and demonstrates a -42% hallucination reduction via RAG. The annotations mark which sentences in scientific text are supported by which cited papers, enabling fine-grained evaluation of citation faithfulness. The dataset covers diverse domains to ensure broad applicability.

The RAG-based approach using these annotations trains models to generate text where each claim is grounded in specific cited sources. The -42% hallucination reduction demonstrates the effectiveness of explicit citation attribution training for reducing unsupported claims in scientific text.
