## Description

ResearchPilot is a local-first multi-agent system for literature synthesis designed to run entirely on consumer hardware without cloud API dependencies. It uses a collection of specialized local LLM agents (each role uses a smaller, locally-run model) that collaborate to retrieve, analyze, and synthesize scientific literature.

The architecture: (1) Local Retriever Agent — runs embedding search on a local paper index (downloaded PDFs or a local corpus); (2) Local Analyst Agent — extracts structured information from retrieved papers; (3) Local Writer Agent — generates synthesis text; (4) Local Reviewer Agent — evaluates quality and identifies gaps. All agents use quantized local LLMs (e.g., Llama, Mistral) running on consumer hardware.

The local-first design addresses cost and privacy concerns of cloud-dependent systems. Performance trades off against cloud-based systems — local models produce lower quality output than frontier models like GPT-4 — but the system is fully self-contained and can operate offline.

## Category Rationale

ResearchPilot uses multiple specialized agents (Retriever, Analyst, Writer, Reviewer) each running on different local LLM instances. While coordination is sequential, the role specialization qualifies it as a multi-agent architecture.

## Limitations

- Lower quality than cloud-based frontier model systems
- No citation graph awareness
- Local model capabilities limit sophisticated analysis
- Local paper index requires manual curation or pre-downloading
