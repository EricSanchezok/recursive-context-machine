## Method Description

PaperQA is an end-to-end retrieval-augmented generation agent for scientific research that performs citation chaining as a core retrieval strategy. Given a research question, PaperQA: (1) retrieves relevant papers via embedding similarity search, (2) extracts claims and evidence from retrieved papers, (3) performs citation chaining — following forward and backward citations to find additional relevant papers, (4) iterates the retrieval and chaining process, and (5) synthesizes findings with inline citations to source papers.

The citation chaining is a key differentiator from standard RAG: rather than relying on a single retrieval pass, PaperQA expands its literature coverage by following citation trails, discovering papers that embedding similarity alone would miss. The LitQA benchmark was introduced alongside PaperQA to evaluate scientific QA systems.

## Category Rationale

PaperQA operates as a single agent with iterative retrieval and citation chaining. Despite the sophisticated retrieval loop, it is a single-agent pipeline where one LLM handles all stages (retrieve, chain, synthesize) rather than multiple specialized agents coordinating.

## Limitations

- Single agent may miss coverage in highly interdisciplinary topics
- Citation chaining depth is limited by API constraints
- Quality depends on initial embedding retrieval quality
- Does not generate structured surveys — focused on question answering
