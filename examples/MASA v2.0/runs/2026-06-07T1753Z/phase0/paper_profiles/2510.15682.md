## Method Description

SQuAI is a 4-agent RAG system for scientific question answering over 2.3M arXiv papers, using hybrid sparse-dense retrieval. The four agents are: (1) Query Analyzer — decomposes the question into sub-questions and identifies required evidence types, (2) Retriever — performs hybrid sparse (BM25) and dense (embedding) retrieval for each sub-question, (3) Evidence Extractor — extracts relevant passages from retrieved papers, and (4) Synthesizer — integrates evidence across sub-questions into a coherent answer with citations.

The hybrid sparse-dense retrieval combines the precision of keyword matching with the semantic coverage of embedding similarity. The multi-agent decomposition enables the system to handle complex questions that require evidence from multiple papers and perspectives.
