## Method Description

This paper models time preference distributions for citation re-ranking in citation recommendation. Rather than treating all citations equally, it models the probability that a user wants to cite a paper from a particular year, conditioned on the query context. The time preference distribution is learned from historical citation data and used to re-rank recommendation results to match expected temporal distribution.

The method handles cold-start scenarios (papers without citation history) by leveraging metadata features (venue, author seniority, topic) to infer the expected time preference. This is directly applicable to survey generation systems that need to balance foundational (older) and contemporary (recent) citations in generated surveys.
