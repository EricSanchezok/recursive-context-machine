## Method Description

DimInd introduces a multi-level compression framework for literature review that progressively transforms papers into structured representations. The pipeline compresses information across three levels: (1) Papers → Structured Tables — each paper is summarized into a table row with columns for key facets (method, dataset, finding, limitation); (2) Tables → Taxonomies — the system analyzes the facet tables to identify recurring patterns and organizes them into a hierarchical taxonomy of approaches, methods, and findings; (3) Taxonomies → Narrative Synthesis — the taxonomy structure is used as the organizing backbone for generating narrative survey sections.

The key insight is that intermediate structured representations (tables and taxonomies) provide a more reliable foundation for synthesis than directly generating narrative from paper abstracts. The facet extraction step ensures that each paper's contributions are captured in comparable dimensions, enabling systematic comparison across papers. The taxonomy step explicitly models the relationships between approaches, making the narrative synthesis more coherent.

Human evaluation with 23 researchers assessed the quality of generated surveys across dimensions including accuracy, organization, and usefulness. The system is notable for its emphasis on structured intermediate representations rather than end-to-end generation.

- agent_count: 1 (single LLM driving multi-level compression pipeline)
- coordination_pattern: "sequential compression — papers → facet tables → taxonomies → narrative synthesis"

- citation_graph_detail: "not used — paper set is assumed to be provided or retrieved via simple search"
- iteration_strategy: "single_pass (compression pipeline is linear, no refinement loops)"

## Key Innovations

- Multi-level compression from papers to facet tables to taxonomies to narrative
- Facet-based structured representation enabling systematic cross-paper comparison
- Taxonomy-driven narrative organization for coherent survey structure
- Human evaluation with 23 researchers across multiple disciplines

## Method Category

single_agent_pipeline

## Category Rationale

DimInd uses a single LLM to drive a multi-level compression pipeline (papers → tables → taxonomies → narrative). There is no multi-agent coordination, no user interaction, and no retrieval innovation. The contribution is in the structured representation approach, not in multi-agent or retrieval architecture.

## Limitations

- No citation graph awareness — paper set is assumed to be given
- Single LLM for all compression stages — no specialized agents for different representation levels
- Linear pipeline with no iterative refinement between stages
- Evaluation limited to 23 researchers — relatively small sample size
- Facet extraction quality depends on LLM's ability to correctly categorize paper contributions
