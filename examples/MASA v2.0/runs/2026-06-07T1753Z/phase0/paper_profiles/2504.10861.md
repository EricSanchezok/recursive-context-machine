## Method Description

Ai2 Scholar QA is an open-source scientific question-answering system that provides organized literature synthesis with explicit attribution to source papers. The system implements a RAG pipeline over a scientific corpus, where each generated claim is accompanied by citations to supporting papers. The pipeline processes user queries by (1) retrieving relevant papers via embedding similarity search, (2) extracting evidence passages from retrieved papers, (3) synthesizing an answer with inline citations, and (4) providing a bibliography of cited works.

The attribution mechanism ensures that every factual statement in the generated answer is traceable to a specific source paper and passage. This is achieved by requiring the LLM to cite specific papers for each claim, with the retrieval stage providing the candidate sources. The system is designed to be transparent and verifiable, enabling users to check the evidence behind any claim.

## Category Rationale

Ai2 Scholar QA operates as a single RAG pipeline where one LLM handles retrieval, synthesis, and attribution. Despite the attribution requirement adding complexity, the system uses a single agent architecture without specialized multi-agent coordination. This places it in single_agent_pipeline.

## Limitations

- No citation graph traversal for literature discovery
- Single-pass generation without iterative refinement
- Attribution quality depends on retrieval quality
- Designed for QA rather than comprehensive survey generation
