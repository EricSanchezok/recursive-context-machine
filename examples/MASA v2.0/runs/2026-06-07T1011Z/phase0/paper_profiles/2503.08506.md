## Description

ReviewBench is a benchmark for evaluating LLM-generated peer review comments, providing 142K review comments with structured reasoning annotations across multiple dimensions (novelty assessment, methodological critique, clarity evaluation, reproducibility check). The companion Review-CoT dataset provides chain-of-thought reasoning traces for review comment generation.

The benchmark includes: (1) Review-CoT dataset with 142K structured review comments annotated with reasoning chains; (2) Multi-dimensional evaluation covering criticism quality, justification depth, actionability, and constructiveness; (3) Evaluation protocols for both full review generation and section-level review writing.

While focused on peer review rather than survey generation, ReviewBench is relevant because it evaluates citation-aware critical analysis — assessing whether LLMs can properly evaluate how papers cite and position themselves relative to prior work.
