## Method Description

ARISE introduces a rubric-guided iterative refinement architecture where a modular set of LLM agents collaboratively produces a survey, guided by a formal quality rubric. The rubric defines quality criteria across multiple dimensions (coverage, organization, citation accuracy, clarity, novelty assessment), and each agent's output is evaluated against this rubric before the next stage proceeds.

The architecture consists of: (1) a Planning Agent that analyzes the topic and produces a structured survey plan using the rubric as a guide for what constitutes good coverage; (2) a Retrieval Agent that gathers papers via search and citation traversal; (3) a Drafting Agent that writes section content; (4) an Evaluation Agent that scores each section against the rubric dimensions, identifying specific deficiencies; (5) a Revision Agent that takes the evaluation feedback and revises the draft to improve rubric scores. The refinement loop continues until all rubric dimensions meet a preset quality threshold (reported as 92.48 overall quality score).

The rubric-guided approach is significant because it provides explicit, interpretable quality criteria that both the generation and evaluation agents can reference. This contrasts with implicit quality guidance (e.g., through training data or prompt instructions) and enables targeted improvement on specific dimensions.

## Key Innovations

- Formal quality rubric explicitly guiding both generation and evaluation
- Iterative refinement loop with per-dimension rubric scores and targeted revision
- Modular 5-agent architecture with clear role separation
- Quantitative quality threshold (92.48 score) as termination criterion

## Category Rationale

ARISE uses five specialized LLM agents (Planning, Retrieval, Drafting, Evaluation, Revision) coordinated around a formal quality rubric. The rubric-guided iterative refinement loop is a genuine multi-agent architecture where different agents perform distinct roles, interact through the rubric scoring mechanism, and iterate until quality targets are met.

## Limitations

- Citation graph traversal limited to BFS — no multi-hop or hierarchical expansion
- Rubric dimensions must be pre-defined and may not capture domain-specific quality aspects
- Five-agent architecture increases computational cost and latency
- Quality threshold (92.48) is system-defined — relationship to human-judged quality is not established
