## Method Description

This paper proposes a step-by-step prompt decomposition strategy for survey generation, where the survey writing task is broken into a sequence of structured sub-prompts: generate title → generate abstract → generate headings → generate content for each heading. The approach is purely prompt-engineering based, requiring no external retrieval system or multi-agent architecture.

The workflow is: (1) Title Generation — given a topic, the LLM generates a survey title; (2) Abstract Generation — based on the title, the LLM generates a high-level abstract summarizing the survey's scope and contributions; (3) Heading Generation — the LLM proposes section and subsection headings that would comprehensively cover the topic; (4) Per-Section Content Generation — for each heading, the LLM generates section content using the title, abstract, and preceding sections as context.

The paper's core contribution is demonstrating that step-by-step prompt decomposition produces more coherent and comprehensive surveys than direct "write a survey about X" prompting. The method is simple, requires no additional infrastructure, and can be applied to any LLM. However, without external retrieval, the generated surveys rely entirely on the LLM's parametric knowledge, which limits factual accuracy and citation reliability.

## Method Category

## Category Rationale

The method uses a single LLM with a structured chain of prompts. There is no retrieval, no multi-agent coordination, no user interaction, and no iterative refinement. The sole contribution is prompt decomposition strategy.

## Limitations

- No external retrieval — entirely dependent on LLM parametric knowledge, limiting factual accuracy
- No citation generation or verification — generated surveys lack grounded citations
- Single-pass with no refinement or quality checking
- Survey quality is bounded by the LLM's training data coverage of the topic
