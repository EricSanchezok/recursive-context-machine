## Method Description

This comprehensive survey provides a bidirectional review of how LLMs interact with citations: (1) LLM-for-Citation — using LLMs to generate, recommend, and analyze citations, and (2) Citation-for-LLM — using citations to improve LLM training, grounding, and evaluation. The survey covers citation generation, citation recommendation with LLMs, citation-aware language models, and evaluation of citation quality in LLM outputs.

The bidirectional framing reveals the two-way relationship between LLMs and citations: LLMs can improve citation practices, while citation structures can improve LLM performance through grounding and training. This provides a comprehensive framework for understanding citation-aware LLM systems.
