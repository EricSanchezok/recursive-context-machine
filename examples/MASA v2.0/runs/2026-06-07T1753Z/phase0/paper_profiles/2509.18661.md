## Method Description

Agentic AutoSurvey extends AutoSurvey with a 4-agent multi-agent framework, achieving 8.18/10 vs AutoSurvey's 4.77/10 on survey quality. The four agents are: (1) Planner — generates a detailed survey outline with section-level search queries, (2) Researcher — executes literature searches for each section using hybrid retrieval, (3) Writer — drafts each section based on retrieved literature, and (4) Reviewer — evaluates the complete survey and provides revision feedback.

The agents communicate through a shared task board, passing section drafts and feedback between roles. The multi-agent coordination enables parallel work (Researcher searches while Planner refines) and quality feedback (Reviewer identifies gaps that Researcher fills). The dramatic quality improvement (8.18 vs 4.77) demonstrates the value of multi-agent specialization for survey generation.

## Category Rationale

Agentic AutoSurvey uses 4 specialized agents with distinct roles (Planner, Researcher, Writer, Reviewer) coordinating via a shared task board. This clear division of labor with agent specialization qualifies it as a multi_agent_pipeline.

## Limitations

- No citation graph traversal — relies on hybrid semantic/keyword retrieval
- Four-agent coordination adds computational overhead
- Quality depends on each agent's LLM capability
- Shared task board may introduce coordination delays
