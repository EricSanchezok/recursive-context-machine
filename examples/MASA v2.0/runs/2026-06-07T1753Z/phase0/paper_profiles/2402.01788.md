## Method Description

LitLLM is a RAG-based toolkit for scientific literature review that uses re-ranking by abstract similarity. The pipeline: (1) retrieves papers using keyword and embedding search, (2) re-ranks retrieved papers by abstract similarity to the query or seed paper, (3) extracts key information from top-ranked papers, and (4) generates section drafts with citations.

The re-ranking step improves precision by prioritizing papers whose abstracts are most similar to the query, filtering out papers that match on keywords but are topically divergent. The toolkit design makes it modular and configurable for different review types.

## Category Rationale

LitLLM is a single RAG pipeline with re-ranking. Despite the modular toolkit design, it operates as a single-agent system.

## Limitations

- No citation graph traversal — relies on text similarity
- Re-ranking may miss papers with different terminology but relevant content
- Single-pass generation without iterative refinement
- Toolkit design requires user configuration
