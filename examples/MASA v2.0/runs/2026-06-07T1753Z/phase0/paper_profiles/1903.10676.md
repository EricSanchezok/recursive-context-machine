## Method Description

SciBERT is a pretrained language model for scientific text, trained on a large corpus of full-text scientific papers from Semantic Scholar (1.14M papers, 3.1B tokens). The model uses the BERT architecture but is trained from scratch on scientific text rather than general text, using a domain-specific vocabulary (SciVocab) built from the scientific corpus.

SciBERT demonstrates that domain-specific pretraining significantly outperforms general BERT on scientific NLP tasks including named entity recognition, relation extraction, and classification. The model has become a standard foundation for scientific text processing, serving as the embedding backbone for many citation-aware retrieval systems. While not specifically designed for survey generation, SciBERT provides the scientific language understanding capability that underlies many survey agent systems.
