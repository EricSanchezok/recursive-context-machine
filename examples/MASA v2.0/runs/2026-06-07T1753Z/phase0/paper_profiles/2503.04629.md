## Method Description

SurveyForge introduces a Scholar Navigation Agent for memory-guided retrieval and outline-driven survey generation, evaluated on SurveyBench. The system features: (1) a Scholar Navigation Agent that simulates how a human scholar navigates literature — moving from broad overviews to specific papers, following citation trails, and building mental models of the research landscape, (2) memory-driven retrieval where the agent maintains a working memory of papers encountered and uses it to guide further retrieval, and (3) outline heuristics that generate a survey outline informed by the memory state.

The navigation agent decides which papers to explore, which citation trails to follow, and when retrieval is sufficient for each section. The memory component prevents redundant retrieval and ensures coverage across the topic. The system was evaluated on SurveyBench, which includes 100 human-written surveys for reference comparison.

## Category Rationale

SurveyForge uses a single Scholar Navigation Agent with memory-guided retrieval. Despite the sophisticated navigation strategy, it is a single agent that manages its own memory and decisions, placing it in single_agent_pipeline.

## Limitations

- Navigation decisions may have variable quality depending on LLM capability
- Working memory may not scale to very large literature collections
- Citation-following depth is bounded by API constraints
- Evaluated on CS-only SurveyBench data
