## Method Description

Citegeist is a system for automated generation of related work analysis on the arXiv corpus. It uses a dynamic RAG approach where: (1) a seed paper or topic query is embedded using a scientific language model, (2) similar papers are retrieved from arXiv via embedding similarity, (3) a multi-stage filtering pipeline removes irrelevant or low-quality matches, and (4) the filtered results are synthesized into a coherent related work section with citation relationships.

The multi-stage filtering combines threshold-based filtering (removing papers below a similarity threshold), diversity filtering (ensuring coverage across different approaches rather than near-duplicates), and quality filtering (preferring papers from reputable venues or with high citation counts). The synthesis stage organizes the filtered papers thematically, producing a related work discussion that groups papers by approach, finding, or methodology.

## Category Rationale

Citegeist operates as a single pipeline with embedding retrieval, multi-stage filtering, and thematic synthesis stages. Despite the sophisticated filtering, it is a single-agent pipeline where one LLM handles all stages sequentially. This places it in single_agent_pipeline.

## Limitations

- No citation graph traversal — misses structural citation relationships
- Single-pass generation without iterative refinement
- Quality filtering based on citation counts may introduce prestige bias
- Embedding similarity alone may miss relevant work using different terminology
