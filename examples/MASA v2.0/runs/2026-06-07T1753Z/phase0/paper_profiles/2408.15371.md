## Method Description

This paper proposes a temporal graph neural network for paper recommendation that explicitly models the evolution of citation networks over time. Unlike static GNN approaches that treat the citation graph as a single snapshot, the temporal GNN maintains time-aware embeddings that update as new papers and citations are added to the graph. The architecture combines a GNN encoder (for structural neighborhood aggregation) with a recurrent neural network (RNN) memory module (for temporal dynamics modeling).

For each paper, the embedding is a function of both its current citation neighborhood (which papers it cites and which cite it) and its historical embedding trajectory (how its role in the citation network has evolved). The RNN module processes the sequence of graph snapshots to capture how a paper's influence and topical focus change over time. This enables recency-aware retrieval — papers that are newly influential in a field can be identified even if they lack a long citation history. The paper recommendation is performed via embedding similarity, with temporal dynamics informing the relevance scoring.

- Temporal GNN architecture that models citation network evolution over time
- RNN memory module for tracking how paper embeddings change across graph snapshots
- Recency-aware retrieval that identifies newly influential papers without long citation histories
- Explicitly addresses the temporal dynamics gap in static citation graph embeddings

## Category Rationale

This paper enhances citation graph retrieval with temporal dynamics modeling. The GNN+RNN architecture processes the dynamic citation graph to produce time-aware paper embeddings for recommendation. Graph structure is central to the method, placing it in graph_enhanced_retrieval.

## Limitations

- Requires multiple temporal snapshots of the citation graph, which may not be available for all domains
- RNN memory may have difficulty with very long citation histories (papers spanning decades)
- Does not incorporate content signals (abstracts, full text) — purely structural
- Recommendation task is paper-level, not survey-level
