## Method Description

SciSage introduces a "reflect-when-you-write" paradigm where each section is drafted with simultaneous reflection on quality, coverage, and citation accuracy. The core innovation is a hierarchical Reflector Agent that monitors the writing process in real-time, flagging issues as they arise rather than in a separate refinement phase.

The architecture uses multiple specialized agents: (1) a Planner Agent that designs the survey structure based on topic analysis; (2) a Retriever Agent that gathers papers using hybrid search and citation graph traversal; (3) a Writer Agent that drafts sections; (4) a hierarchical Reflector Agent that evaluates drafts in real-time across multiple quality dimensions, providing immediate feedback that the Writer Agent incorporates before proceeding. The Reflector operates at two levels: a local reflector that checks individual paragraphs and citations, and a global reflector that monitors overall survey coherence and coverage.

SciSage also contributes the SurveyScope benchmark — 46 high-impact papers across 11 computer science domains (2020–2025) with human-written surveys as reference. The citation-aware evaluation uses Citation F1 as a metric for citation quality.

## Category Rationale

SciSage uses four distinct agent roles (Planner, Retriever, Writer, Reflector) with the novel reflect-when-you-write coordination pattern. The hierarchical Reflector (local + global) is a genuine architectural innovation in multi-agent coordination for survey generation. Agents are specialized and interact in real-time, not just sequentially.

## Limitations

- Real-time reflection increases latency and computational cost during drafting
- Citation graph traversal is single-level BFS — no multi-hop or hierarchical organization
- Reflector agent quality depends on the underlying LLM's evaluation capability
- SurveyScope benchmark limited to 46 papers across 11 CS domains — may not generalize
