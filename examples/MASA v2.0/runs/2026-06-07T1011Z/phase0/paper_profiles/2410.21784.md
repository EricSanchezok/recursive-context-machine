## Description

MARCO introduces a real-time chat-based multi-agent orchestration framework where agents collaborate through structured chat conversations to accomplish research tasks, including literature synthesis. The system treats the research process as a collaborative conversation where agents with different capabilities discuss, debate, and converge on findings.

The architecture: (1) Agent roles include Searcher, Analyst, Writer, Critic, and Summarizer; (2) Agents communicate through a shared chat channel with structured message types (question, answer, proposal, critique, summary); (3) A Conversation Manager agent tracks discussion state, ensures progress, and manages turn-taking; (4) Real-time streaming allows agents to process and respond as information becomes available.

The real-time chat paradigm enables dynamic information exchange where retrieval results can be immediately discussed and critiqued. This contrasts with sequential pipeline architectures where each stage completes before the next begins.
