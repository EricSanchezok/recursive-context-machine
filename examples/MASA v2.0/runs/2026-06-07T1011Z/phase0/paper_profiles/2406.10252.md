## Method Description

AutoSurvey is a foundational multi-stage pipeline for automated survey generation that decomposes the survey writing process into a sequence of distinct phases: retrieval, outline generation, subsection drafting, integration, and evaluation. The system first retrieves relevant papers from a large corpus (e.g., arXiv or Semantic Scholar) using keyword-based and embedding-based search for a given topic query. It then generates a structured outline for the survey by asking an LLM to produce section and subsection headings based on the retrieved paper set.

Each subsection is drafted independently by the LLM using the relevant retrieved papers as source material. The system then integrates all subsections into a coherent full survey, performs consistency checks, and optionally generates a human-readable evaluation. AutoSurvey operates as a single-agent pipeline where one LLM (typically GPT-4) drives all stages sequentially through carefully engineered prompts. The key architectural insight is that decomposing survey writing into smaller, focused sub-tasks (outline, per-section drafting, integration) improves output quality compared to monolithic generation.

A notable design choice is the clear separation between retrieval and generation: retrieval is entirely offline and performed once before generation begins. This means the model does not perform iterative or multi-round retrieval during writing, limiting the system's ability to catch gaps or refine its source material mid-generation. The evaluation stage uses both automatic metrics (e.g., ROUGE, BLEU) and LLM-based quality scoring across dimensions like coverage, coherence, and citation quality.

## Architecture

- agent_count: 1 (single LLM driving all stages via prompts)
- coordination_pattern: "sequential pipeline — retrieval → outline → per-section drafting → integration → evaluation"
- retrieval_method: "hybrid (keyword + embedding-based search from arXiv/Semantic Scholar)"
- citation_graph_awareness: "none"
- citation_graph_detail: "not used — papers are retrieved via search queries, not citation graph traversal"
- iteration_strategy: "single_pass (no iterative refinement between stages)"

## Key Innovations

- First end-to-end LLM-based survey generation pipeline decomposing the task into retrieval, outline, drafting, integration, and evaluation stages
- Demonstrates that LLMs can produce coherent multi-section surveys (>5,000 words) on specialized topics
- Establishes a baseline evaluation framework for automated survey quality assessment

## Method Category

single_agent_pipeline

## Category Rationale

AutoSurvey uses a single LLM (GPT-4) to drive all stages of the survey generation process through prompt engineering. There is no multi-agent orchestration, no user interaction loop, and no iterative refinement between stages. Each phase (retrieval, outline, drafting, integration) is a distinct prompt to the same LLM executed in sequence.

## Limitations

- No iterative refinement — retrieval is performed once upfront and not revisited during writing
- No citation graph awareness — papers are discovered via keyword/embedding search only, missing citation chaining benefits
- Single LLM prompt design limits ability to incorporate diverse perspectives or specialized knowledge
- Evaluation limited to small-scale human studies on 10 CS topics
- No explicit citation quality or attribution mechanism — citations are generated from the retrieval set without verification
