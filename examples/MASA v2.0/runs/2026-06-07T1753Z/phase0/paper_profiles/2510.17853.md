## Method Description

CiteGuard is a system for faithful citation attribution that uses RAG validation, achieving 65.4% on the CiteME benchmark (vs human 69.7%). The system: (1) generates text with citation claims, (2) retrieves supporting evidence for each claim using RAG, (3) validates each citation against the retrieved evidence to check if the cited paper actually supports the claim, and (4) flags or corrects unsupported citations.

The validation step is the key innovation: rather than assuming citations are correct, CiteGuard actively checks each citation against the cited paper's content. This reduces hallucinated or misattributed citations. The 65.4% vs 69.7% human performance suggests near-human citation verification capability.

## Method Category

single_agent_pipeline

## Category Rationale

CiteGuard is a single pipeline for citation validation. It verifies citations against source papers but operates as a single agent system.

## Limitations

- Post-generation validation cannot fix all citation errors
- Retrieval for validation requires access to cited paper full text
- 65.4% accuracy still leaves room for improvement
- Does not prevent citation errors during generation — only catches them post-hoc
